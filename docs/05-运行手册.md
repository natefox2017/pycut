# 运行手册

## 环境要求

- Python 3.10+
- FFmpeg 8.x（含 ffprobe）
- `hatch_gws_cli`（Google Drive，已在 Arlo 云电脑预装并连接）
- 无需 pip 安装第三方包（纯标准库）

## 常用命令

```bash
cd ~/workspace/pycut

# 扫描目录（只读，列出视频与大小）
python -m pycut scan --path 颗粒/爆款素材/抖音

# AI 分析：生成证据包（分段+代表帧），AI 看帧后填 decisions.json
python -m pycut analyze --path 颗粒/爆款素材/抖音 --limit 1

# 功能一：长视频切片（爆款素材；--decisions 指定 AI 决策目录则用 AI 切点+分类）
python -m pycut slice --path 颗粒/爆款素材/抖音 --path 颗粒/爆款素材/快手
python -m pycut slice --path 颗粒/爆款素材/抖音 --decisions run/decisions

# 功能一：短视频直接入库（手机录制/死老鼠）
python -m pycut import-shorts --path 颗粒/片段/片段手机录制 --path 颗粒/片段/死老鼠

# 试运行（下载+处理，不上传/不写台账）
python -m pycut slice --path 颗粒/爆款素材/抖音 --dry-run

# 整理视频：清理重复文件与系统垃圾（进回收站，可撤销）
python -m pycut organize --path 颗粒
python -m pycut organize --path 颗粒 --dry-run   # 只报告，不删除

# 产品信息表（话术的唯一事实来源）
python -m pycut product

# 话术转录准备：抽字幕帧供 Arlo 读字幕整理话术
python -m pycut transcribe --path 颗粒/爆款素材/抖音 --limit 2 --every 5

# 任务单（每批处理前的用户确认关口）
python -m pycut taskform new --path 颗粒 --name 任务单-2026-10-01.xlsx
# 用户在手机上填写 → 状态改为"已填写" → 聊天里告诉我
python -m pycut taskform read --path 颗粒 --name 任务单-2026-10-01.xlsx
```

## 任务单流程（用户 2026-10-01 确认）

每次处理前 Arlo 按当前规划生成 xlsx 任务单并上传到网盘目录
（三张表：本批任务 / 产品信息 / 话术）。用户在手机上填写，填完把
"状态"改为"已填写"再通知 Arlo。Arlo 下载校验后**只执行表内事项**：

- 状态不是"已填写" → 拒绝执行；
- 处理范围只认规划内目录（爆款素材/抖音/快手、片段两类），表里写别的只警告、不处理；
- 产品信息表覆盖 product.yaml，作为本批话术的事实来源；
- 话术表一行一条，经 `product.check_script()` 事实核对。

## 产品信息表

`product.yaml`（仓库根目录）在话术生成中的地位是**唯一事实来源**。
用户改此表 = 告诉 Arlo 产品核心特点。当前内容：灭鼠颗粒 / 红色颗粒 /
19元11包 / 安全灭鼠 / 对牲畜友好 / 安全低毒 / 老鼠食用后慢性中毒死亡。
`pycut/product.py` 提供解析与 `check_script()` 事实核对（价格/颜色/禁止说法）。
