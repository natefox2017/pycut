# 运行手册

## 环境要求

- Python 3.10+
- FFmpeg 8.x（含 ffprobe）
- `hatch_gws_cli`（Google Drive，已在 Arlo 云电脑预装并连接）
- 无需 pip 安装第三方包（纯标准库）

## 已确认的目录映射（2026-10-01 用户指定）

项目根目录：`颗粒/`（网盘 ID 见 `pycut/config.py`）

| 目录 | 作用 | 功能一处理方式 |
|---|---|---|
| 颗粒/爆款素材/抖音（70 视频/5.3G） | 待切片长视频 | slice：场景检测 + 切点规划 + 逐段导出 |
| 颗粒/爆款素材/快手（3 视频/181M） | 待切片长视频 | slice：同上 |
| 颗粒/片段/片段手机录制（197 视频/1.4G） | 短视频 | shorts：不切割，直接标准化入库 |
| 颗粒/片段/死老鼠（1 视频） | 短视频 | shorts：不切割，混剪时按需拼接 |
| 颗粒/主图 | 产品图片 | assets：功能二混剪时由 Arlo 决定拼入时机 |

## 常用命令

```bash
cd ~/workspace/pycut

# 扫描目录（只读，列出视频与大小）
python -m pycut scan --path 颗粒/爆款素材/抖音

# 功能一：长视频切片（爆款素材）
python -m pycut slice --path 颗粒/爆款素材/抖音 --path 颗粒/爆款素材/快手

# 功能一：短视频直接入库（手机录制/死老鼠）
python -m pycut import-shorts --path 颗粒/片段/片段手机录制 --path 颗粒/片段/死老鼠

# 试运行（下载+处理，不上传/不写台账）
python -m pycut slice --path 颗粒/爆款素材/抖音 --dry-run
```
