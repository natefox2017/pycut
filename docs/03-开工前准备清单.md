# 开工前准备清单

按顺序逐项确认，全部打勾后才能开工。 pilot（试跑一批）通过后再全量。

## 1. 账号与连接

- [ ] Google Drive 已连接（Arlo 侧验证 `drive status` 为 connected）
- [ ] 用户已提供各目录的网盘分享地址
- [ ] Arlo 已扫描全部目录，[04-目录作用确认表](04-目录作用确认表.md) 已填完并经用户确认

## 2. 规则确认（功能一：整理切片）

- [ ] 时长规则：**<10 秒的视频不切片**（用户已确认，覆盖仓库默认 min=2s）
- [ ] 切片时长上限：默认 8 秒（与仓库 `docs/SLICE-PREPARATION.md` §5 一致），如需调整由用户指定
- [ ] 输出规格：9:16、分辨率档（默认 1080×1920）、CFR 30、H.264 yuv420p SDR BT.709
- [ ] 分类体系：结果证明 / 人物口播 / 使用过程 / 使用场景 / 商品特写 / 待复核（新增需用户确认）
- [ ] 切片库位置：项目根目录 `切片库/`（Arlo 新建）

## 3. 规则确认（功能二：混剪成片）

- [ ] 话术文件已就位：UTF-8 编码，每行一条独立话术，空行跳过
- [ ] 声音方案：用户音频原样用 / TTS 配音（二选一；TTS 需提前确认音色）
- [ ] 去重强度默认档：中（轻 / 中 / 强，见[处理流程](01-处理流程.md)对照表）
- [ ] 成片规格：9:16、分辨率档、单条目标时长范围
- [ ] 成片输出位置：项目根目录 `成片/<批次>/`（Arlo 新建）

## 4. 台账

- [ ] `EasyCut-处理进度.md` 已在项目根目录创建
- [ ] 字段口径一致：路径 + MD5 为去重主键

## 5. 环境与风险

- [ ] FFmpeg 版本确认（当前云电脑为 8.x）
- [ ] 单批下载量约 1G，本地磁盘可周转（当前可用约 7.5G）
- [ ] 已知风险：云电脑可能被整体替换导致长任务中断 → 按台账断点续跑，不从头来
- [ ] Arlo"看"视频的方式为抽帧 + 元数据 + 场景检测，非逐帧人眼观看，语义判断精度有限

## 6. Pilot 验收

- [ ] 先跑 1 批（约 1G 或 1 个目录）验证下载 → 切片 → 分类 → 上传 → 台账全链路
- [ ] 用户抽查切片质量（切点、分类、画质）后书面确认，再进入批量
- [ ] 混剪功能首次运行时同样先跑 1 批（如 3–5 条）给用户看效果，确认后再批量
