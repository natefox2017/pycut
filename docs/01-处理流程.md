# 处理流程

总链路（两个功能共用同一套流转骨架）：

```text
网盘源目录 → 分批下载（约 1G/批） → 本地处理 → 按类上传回网盘
    → 更新 EasyCut-处理进度.md（路径 + MD5） → 删除本地副本 → 下一批
```

台账是唯一事实来源：中断、重跑、续跑一律以台账为准，已记录 MD5 的源文件不再重复处理。

---

## 功能一：整理切片

### 步骤

1. **用户提供目录**：用户给出长视频目录的网盘分享地址（可多个）。
2. **扫描与确认**：Arlo 扫描每个目录，输出文件清单；逐个确认每个目录的作用（Arlo 提问，或用户直接告知），填入 [04-目录作用确认表](04-目录作用确认表.md)。作用类型：`待切片长视频` / `已整理切片` / `话术` / `成片输出` / `其他`。
3. **建切片库**：在网盘项目根目录新建 `切片库/`（如不存在），按[命名规范](02-文件夹命名规范.md)建好分类子目录。
4. **分批下载**：每批约 1G，按目录顺序取；下载后计算 MD5，命中台账已处理记录的直接跳过（不重复下载处理）。
5. **元数据初筛**：ffprobe 读取时长/分辨率/帧率/音轨。**时长 <10 秒的视频不切片**，记为 `skipped_short`，不进入后续步骤。
6. **切点分析**：场景检测（FFmpeg select 滤镜）+ 按时间点抽帧，Arlo 看帧定切点与分组。切点规则与 `docs/SLICE-PREPARATION.md` §5 一致：整段保留优先、尾段重分配（如 9 秒切 5+4 而非 8+1 丢 1 秒）、不机械等分、不拼不连续画面。
7. **切片与标准化**：FFmpeg 按切点导出，统一 9:16、分辨率档、CFR、H.264 yuv420p SDR BT.709（与 `docs/SLICE-PREPARATION.md` §6 一致）。不加字幕/音乐/贴纸/转场，不改原声。
8. **质量检查**：probe + 完整解码 + 时长/画幅/色彩校验，不合格的记 `failed`，不冒充完成。
9. **分类上传**：按 Arlo 判定的分类上传到 `切片库/<分类>/`，文件名按规范命名。
10. **更新台账**：`EasyCut-处理进度.md` 记录源视频网盘路径、文件名、MD5、大小、切片数、输出目录、状态、时间。
11. **清理与下一批**：删除本地副本（含源视频与中间文件），处理下一批。

### 状态定义

| 状态 | 含义 |
|---|---|
| `done` | 切片完成并已上传，台账已记 |
| `skipped_short` | 时长 <10 秒，未切片 |
| `skipped_done` | MD5 命中台账已处理，跳过 |
| `failed` | 损坏/解码失败/校验不通过，需人工看 |
| `missing` | 台账有记录但网盘源文件已不在，需用户处理 |

### 禁止事项

- 不把 `切片库/` 已输出的切片重新当作源视频处理（防止循环）。
- 不覆盖网盘已有同名成功切片；文件名含源 MD5 前 8 位天然去重。
- 不删除、不移动用户的源视频文件。

## 功能二：混剪成片

### 前置条件

- `切片库/` 已有可用切片；话术文件已就位（UTF-8，每行一条独立话术）。

### 步骤

1. **用户下达混剪指令**：指定切片来源目录（`切片库/` 下的一个或多个分类）、话术（第几行 / 哪个文件）、成片数量、输出规格、去重强度（轻 / 中 / 强，见下）。
2. **下载物料**：从 `切片库/` 下载所需切片 + 话术文件到本地（不下载长视频）。
3. **批次规划**：N 条成片一次整体规划，不逐条独立随机。规则：
   - 同一条成片内不重复高重叠 source range；
   - 同一批次内 source 分布均衡，记录 usage，避免单一素材过度使用；
   - 固定 seed，可复现；
   - **开头策略**（用户已确认）：用爆款同款开头（开头池轮换，`pycut hooks` 提取），
     只做轻微去重变换（裁剪位移/色调二选一），不做镜像/变速；
   - 素材不足时如实返回缺口，不用循环/无关素材补洞。
4. **声音准备**（二选一，用户指令中指定）：
   - 用户音频：原样使用，不截短、不替换；
   - TTS 配音：话术按原文生成（需提前确认音色；多条成片建议轮换音色/语速做音频去重）。
   - 素材原声默认关闭，避免与主声音冲突。
5. **去重变换**（按强度档叠加，FFmpeg 实现）：

   | 手段 | 轻 | 中 | 强 |
   |---|---|---|---|
   | 镜头重排/时长抖动 | ✓ | ✓ | ✓ |
   | 裁剪位移/缩放微调 | ✓ | ✓ | ✓ |
   | 色调/饱和度/亮度抖动 | — | ✓ | ✓ |
   | 镜像（hflip） | — | ✓ | ✓ |
   | 变速微调（0.9x–1.1x） | — | — | ✓ |
   | 字幕样式/位置变化 | ✓ | ✓ | ✓ |
   | 片头/片尾差异帧 | — | ✓ | ✓ |

   强度越高去重效果越好，但对观感影响越大，默认用"中"，由用户指令覆盖。
6. **渲染**：FFmpeg 按冻结的渲染计划执行（计划一旦冻结不再改、不重选片）。
7. **质量检查**：时长/分辨率/音画同步/文件可解码；抽查成片间重复度（同批两两 source range 重叠率超阈值则 targeted 重抽单条，不整批重随）。
8. **上传**：成品传到 `成片/<批次>/`，批次目录按 `批次-YYYYMMDD-HHMM` 命名。
9. **更新台账**：`EasyCut-处理进度.md`「混剪成片」表记录切片来源、话术版本、成片数、输出目录、状态。
10. **清理本地**：删除本批下载的切片副本与中间文件。

### 失败处理

- 单条渲染失败：只重跑该条，不重排整批，不重新随机选片。
- 中断（云电脑重启）：按台账恢复——已上传成片保留，未完成的条目重跑。
