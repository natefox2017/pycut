# 07 - 云电脑运行指南

> 本指南只针对 Hatch 云电脑（Linux）。换了一台云电脑 / VM 重置后，按 §2 重建环境即可开工。

## 1. 环境概览

云电脑自带、开箱即用的东西：

| 组件 | 说明 |
|---|---|
| Python 3.12 | 系统 Python，主流程零第三方依赖，直接跑 |
| FFmpeg 8 | `ffmpeg` / `ffprobe` 命令行，切片/转码/抽帧全靠它 |
| `hatch_gws_cli` | Google Workspace CLI，Drive 操作经它执行，**认证由运行时托管**，无需配置 |
| `~/workspace` | 持久化目录，VM 重置不丢；`pycut` 仓库在此 |

需要手动建的东西（§2）：

| 组件 | 用途 | 位置 |
|---|---|---|
| 独立 venv | faster-whisper（语音转录），不污染系统 Python | `~/workspace/pycut/.venv` |
| small 模型 | 中文转录（int8 CPU），约 1GB | `~/.cache/huggingface`（自动） |
| openpyxl | 任务单 xlsx 读写，系统 pip + venv 各装一份 | pip |

## 2. 从零搭建（新云电脑）

```bash
# 1. 确认基础工具
python3 --version   # 3.12
ffmpeg -version | head -1
hatch_gws_cli drive --help | head -2

# 2. 建 venv 并装转录依赖（系统 pip 有 PEP 668 限制，必须走 venv）
python3 -m venv ~/workspace/pycut/.venv
~/workspace/pycut/.venv/bin/pip install faster-whisper openpyxl

# 3. 系统 pip 也装 openpyxl（主流程读任务单用）
pip install --break-system-packages -q openpyxl

# 4. 预下载转录模型（约 1GB，第一次转录也会自动下）
env -u no_proxy -u NO_PROXY ~/workspace/pycut/.venv/bin/python -c \
  "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"

# 5. 验证
cd ~/workspace/pycut
python -m pycut scan --path 颗粒/爆款素材/抖音   # 应列出视频
python -m pycut product                          # 应打出产品信息表
```

> 注意：`no_proxy` 环境变量含 IPv6 项（`[::1]`）时 httpx 会崩，
> 所有走 HuggingFace 下载的命令都要加 `env -u no_proxy -u NO_PROXY`。

## 3. 目录结构

```
~/workspace/pycut/
├── pycut/            # 主包（见各模块 docstring，云电脑相关逻辑已注释）
├── docs/             # 本目录（00~07）
├── product.yaml      # 产品信息表（话术唯一事实来源）
├── .venv/            # 转录专用虚拟环境（git 不收录）
└── run/              # 本地中转区（git 不收录）
    ├── downloads/    # 下载中转（处理完删除）
    ├── outputs/      # 切片产出（上传后删除）
    ├── review_pack/  # AI 证据包（保留，可追溯）
    ├── decisions/    # AI 决策 <md5>.json（保留）
    ├── transcribe/   # 字幕帧（话术转录用）
    └── hook_pool/    # 爆款开头池
```

网盘（`颗粒/`）结构见 `docs/02-文件夹命名规范.md`。

## 4. 标准作业流程（一批）

```
1. pycut taskform new --path 颗粒 --name 任务单-YYYY-MM-DD.xlsx
   → 网盘生成任务单，用户在手机上填写，状态改"已填写"后通知
2. pycut taskform read --path 颗粒 --name ...   # 校验，只认表内事项
3. pycut analyze --path 颗粒/爆款素材/抖音 --limit N
   → 生成证据包（含转录句子时间戳，切点已对齐到句尾）
4. Arlo 看帧+看话术，写 run/decisions/<md5>.json（切点+分类+理由）
5. pycut slice --path ... --decisions run/decisions
   → 导出→QC→上传 颗粒/切片库/<分类>/→写台账→删本地
6. 短视频：pycut import-shorts --path 颗粒/片段/片段手机录制
```

## 5. 命令速查

```bash
python -m pycut scan --path 颗粒/爆款素材/抖音            # 扫描（只读）
python -m pycut analyze --path 颗粒/爆款素材/抖音 --limit 2  # AI 证据包
python -m pycut slice --path ... --decisions run/decisions   # 切片入库
python -m pycut import-shorts --path 颗粒/片段/片段手机录制  # 短视频入库
python -m pycut organize --path 颗粒 --dry-run               # 整理视频（先看报告）
python -m pycut taskform new/read --path 颗粒 --name ...      # 任务单
python -m pycut scriptgen prepare/write/extract-opening ...   # 话术
python -m pycut transcribe --path ... --limit 2               # 字幕帧（话术转录）
python -m pycut hooks --path ... --limit 3                    # 开头池
python -m pycut product                                       # 产品信息表
```

## 6. 换云电脑 / VM 重置后恢复

1. `~/workspace` 还在（持久化），先确认 `pycut` 目录完整。
2. 按 §2 重建 `.venv` + 模型（`~/.cache` 可能已清空，模型要重下）。
3. `hatch_gws_cli` 由新运行时提供，无需处理；如 Drive 命令鉴权失败，找运行时支持。
4. 跑 §2 第 5 步验证，通过即开工。
5. 台账在网盘（`EasyCut-处理进度.md`），本地 `run/` 丢了不影响续跑（MD5 去重）。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `pip install` 报 PEP 668 | 系统 Python 被保护 | 主流程依赖用 `--break-system-packages`；转录依赖走 `.venv` |
| 模型下载报 `InvalidURL ... ':1]'` | httpx 解析 `no_proxy` 里的 `[::1]` 崩了 | 命令前加 `env -u no_proxy -u NO_PROXY` |
| 切片失败但台账 note 为空 | 旧版本无 note 列 | 已修复（ledger 有备注列）；重跑即可（failed 可重试） |
| 切片库建在了网盘根目录 | 旧版本路径 bug | 已修复（固定建在 `颗粒/切片库/`）；误建的可进回收站删 |
| 转录很慢 | CPU 转录 320s 音频约需几分钟 | 正常，`--limit` 小批量跑 |
| 转录报 `av.open() got an unexpected keyword argument 'metadata_errors'` | PyAV 19 移除了该参数，与 faster-whisper 1.2.1 不兼容 | 已绕开：`speech.py` 用标准库 wave 解码成 numpy 数组，不走 av。如重装 venv，不要升级 av |
| 某条视频台账显示 failed | 看台账"备注"列的错误信息 | 修好后直接重跑（failed 不会被跳过） |
