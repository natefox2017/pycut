# 06 - 混剪详细设计（功能二）

> 状态：设计文档。代码未实现，按此文档开发。
> 用户已确认：开头用爆款同款（前几秒）+ 轻微去重变换；话术优先从爆款音频转录。

## 1. 输入与输出

- 输入：
  - 网盘 `颗粒/切片库/<分类>/`（功能一产出）
  - 话术：用户提供的音频 **或** 话术文本（`pycut transcribe` 转录整理）
  - 任务单（本批的混剪参数：成片数、规格、话术对应关系）
  - 开头池（`pycut hooks` 提取的爆款同款开头）
- 输出：`颗粒/成片/` 下 N 条成品视频 + 混剪台账。

## 2. 总流程

```
话术音频 → ffprobe 测精确时长 Ta（主轨道，视频向它看齐）
        →（如有文本）按句子分段，得 [t0, t1, ...] 时间轴
选片规划 → 开头钩子（开头池轮换）+ 中间段（按话术分段/时长挑选）
        → 单片段变换（去重层）→ 时长对齐到 Ta
        → 拼接 → 字幕烧录 → BGM → 转场 → 编码输出
        → 台账记录（seed/用料/变换参数，可复现）
```

## 3. 去重机制（四层）

去重是概率工程：以下为行业通用做法，能大幅降低被判重复的概率，
但没有任何方案能"保证"过审（平台算法是黑盒）。

### 3.1 素材调度层（规划时）

- 同一条成片内：不重复使用高重叠的 source range（同一源视频的相邻/重叠切片不同时出现）。
- 同一批次 N 条之间：usage 均衡。记录每条切片被使用次数，优先选低频切片，
  避免"同一条爆款切片出现在每一批成片里"。
- 固定 seed：整批规划可复现、可审计。
- 开头池轮换：多条成片之间轮换不同的爆款开头；只有一个开头时靠 3.2 的轻微变换区分。

### 3.2 单片段变换层（每条切片混剪时）

每次使用时按 seed 从变换组合中随机选，保证**同一源切片在不同成片里呈现不同**：

| 变换 | 参数 | 禁忌 |
|---|---|---|
| 裁剪位移 | 9:16 裁剪框上下/左右偏移 ±3~5% | 避免裁掉字幕主体 |
| 变速 | 0.95~1.05 | 钩子片段不用（保护钩子效果） |
| 色调 | 亮度/饱和度/对比度 ±5% | — |
| 镜像 | 水平翻转 | 有文字/字幕的不镜像；钩子不用 |

### 3.3 结构层

- 片段顺序：开头钩子固定后，中间段顺序打散重排。
- 转场：硬切 / 淡入淡出 / 轻微缩放转场，按 seed 轮换。
- 字幕：见 §8 字幕样式（三种烧录样式轮换）。
- ~~BGM 池~~：用户 2026-10-01 确认不需要，不做。

### 3.4 特效层（针对暗水印，用户 2026-10-01 要求）

平台用暗水印（不可见水印）追踪视频来源，3.1~3.3 的常规变换对暗水印
识别影响不大。因此混剪时叠加**全画面像素级特效**，破坏水印提取：

| 特效 | FFmpeg 实现 | 参数 |
|---|---|---|
| 雪花/噪点 | `noise=alls=N:allf=t`（时域噪点） | N=10~25，按 seed 变化 |
| 胶片颗粒 | `noise=alls=N:allf=t+u` | 轻量，与雪花二选一 |
| 暗角 | `vignette` | 轻微 |

- 特效强度按 seed 在每条成片变化，保证同一源切片在不同成片里噪点 pattern 不同。
- 强度以"不影响观看"为上限：先保证人眼观感，再谈去重。
- 切片库本身保持干净（不加特效），特效只在混剪输出时加，同一源切片可复用不同特效。

### 3.4 文件层

- 重新编码（H.264，GOP/码率与源不同），MD5 必然不同。
- 输出参数（分辨率/码率）批次内轻微差异。

## 4. 时长对齐：话术 30 秒 → 成片 30 秒

**原则：音频是主轨道，视频向音频看齐。宁可视频微变速，不动音频（变调伤听感）。**

1. **测**：ffprobe 取话术音频精确时长 Ta（如 30.0s）。
2. **规划**：钩子（~4s）+ 按话术分段挑选切片，累计 Σ ≈ Ta（允许 ±2s 误差带）。
   - 话术有分段文本时：按句子时间轴一一对应选段；
   - 只有整段音频时：按总时长均匀分配。
3. **微调**：对某条中间切片做 setpts 变速（0.9~1.1），把 Σ 精确调到 Ta。
4. **兜底**：拼接后视频流精确裁剪/补齐到 Ta，与音频 mux，输出加 `-t Ta`，
   保证成片时长 = Ta（精确到 0.1s 内）。
5. 口播类切片尽量不对齐到句子边界做硬切——宁可整段保留，用变速消化误差。

## 5. 开头策略（用户已确认）

- 爆款视频的开头都是同款，用同样的前几秒做开头更容易爆。
- 混剪统一用开头池里的爆款同款开头，只做轻微去重变换（裁剪位移/色调二选一），
  不做镜像/变速等损伤钩子效果的变换。

## 6. 任务单对接

- 混剪只认任务单：成片数、话术（音频或文本）、开头策略确认、产品信息。
- 状态不是"已填写"不执行；表外要求不处理。
- 每条成片台账记录：seed、用料清单（含 source range）、变换参数、话术版本。

## 7. 字幕样式（用户 2026-10-01 要求三种，轮换使用）

实现：话术 → 生成 .ass 字幕文件 → `subtitles` 滤镜（libass）烧录。
字体文件放 `assets/fonts/`（仓库不存，首次运行时下载免费可商用中文字体）。

| 样式 | 说明 | ASS 关键参数 |
|---|---|---|
| 背景框字幕 | 文字带半透明黑底框 | `BorderStyle=3, BackColour=&H80000000` |
| 彩色文字 | 关键词/卖点变色（如价格红色） | `PrimaryColour` 按词指定 |
| 换字体 | 粗黑 / 圆体等不同字体 | `FontName` 切换 |

- 三种样式按 seed 轮换，同一话术在不同成片里字幕样式不同（也是去重的一环）。
- 默认位置底部居中，描边保证小屏可读。

## 8. 成片规格（用户 2026-10-01 确认）

- 默认 1080x1920 / 30fps（与切片库一致）。
- 文件过大或处理吃力时降 720x1280（配置项一键切换）。
