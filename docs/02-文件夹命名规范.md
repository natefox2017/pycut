# 文件夹与文件命名规范

## 网盘目录树（项目根目录下）

```text
<项目根>/                          # 用户提供，如灭鼠项目根目录
├── 长视频-待切片/                  # 用户提供，Arlo 只读扫描、不写入
│   └── ...                        # 用户原有子目录结构保持不动
├── 切片库/                        # ★ Arlo 新建并维护，混剪的唯一输入
│   ├── 结果证明/
│   ├── 人物口播/
│   ├── 使用过程/
│   ├── 使用场景/
│   ├── 商品特写/
│   └── 待复核/                    # 存疑切片，不进入混剪
├── 成片/                          # ★ Arlo 新建并维护，混剪输出
│   ├── 批次-20261001-1200/
│   └── 批次-20261002-0900/
├── 话术.txt                       # 用户提供，UTF-8，每行一条独立话术
├── 主图/                          # 用户原有（封面等），Arlo 不动
└── EasyCut-处理进度.md            # ★ Arlo 维护的台账（路径 + MD5）
```

说明：

- 带 ★ 的由 Arlo 创建与维护；用户原有目录 Arlo 只读不写、不改名、不移动。
- `待复核/` 下的切片默认不进入混剪候选，用户人工确认后可移入对应分类。
- 分类体系沿用项目现有分类（结果证明/人物口播/使用过程/使用场景/商品特写）；新增分类需用户确认后追加。

## 切片文件名

```text
<源MD5前8位>_<序号3位>_<分类>.mp4
```

示例：`a81f3c2d_001_使用过程.mp4`

- 源 MD5 前 8 位：天然去重 + 可追溯源视频；
- 序号：同一源视频内的切片顺序；
- 分类：后缀冗余，便于肉眼识别（权威分类以所在目录为准）。

## 成片文件名

```text
<批次>_<序号3位>.mp4
```

示例：`批次-20261001-1200_001.mp4`，存放在 `成片/<批次>/` 下。

## 批次命名

`批次-YYYYMMDD-HHMM`（北京时间），如 `批次-20261001-1200`。

## 台账文件

- 位置：项目根目录 `EasyCut-处理进度.md`（与网盘目录同级）。
- 更新方式：Arlo 每批处理完后下载 → 追加记录 → 上传覆盖（保留文件 ID）。
- 字段：源视频网盘路径 / 文件名 / MD5 / 大小 / 切片数 / 输出目录 / 状态 / 处理时间；混剪表：切片来源 / 话术版本 / 成片数 / 输出目录 / 状态。

## Arlo 本地工作区

```text
~/workspace/easycut/
├── downloads/        # 本批下载的源视频/切片（处理完即删）
├── work/             # 中间文件（抽帧、临时编码，处理完即删）
├── outputs/          # 本批待上传成品（上传完即删）
└── EasyCut-处理进度.md  # 台账本地副本
```

本地不长期存留任何视频文件；所有持久化只在网盘。
